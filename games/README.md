# Flash Games

Place your `.swf` files in this directory.

## Available Games

- **Dad 'n Me** (`dadnme.swf`): A classic beat 'em up game. Run with `flash dadnme`.
- **The Gun Game** (`thegungame.swf`): A physics-based shooting game. Run with `flash thegungame`.

## Usage

In the terminal, type:

```bash
flash game_name
```

For example:

```bash
flash dadnme
```
